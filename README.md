# Linear Regression from Scratch

A simple implementation of **Linear Regression using NumPy**, trained with Gradient Descent to predict real estate prices.

## Features

* **Vectorized computations** using NumPy for efficient matrix operations.
* **Feature standardization** using Z-score normalization.
* **Mean Squared Error (MSE)** as the loss function.
* **Gradient Descent** implemented from scratch to optimize model parameters.
* **Convergence monitoring** using relative loss improvement and early stopping.
* **Data visualization** with Matplotlib to compare actual and predicted prices.

## Technologies

* Python
* NumPy
* Pandas
* Matplotlib

## Dataset

The model uses a real estate dataset containing property-related features and corresponding prices.

## Learning Objectives

This project was built to develop a deeper understanding of the mathematical foundations of machine learning, including:

* Linear models and vectorized predictions
* Loss functions and partial derivatives
* Gradient descent and parameter optimization
* Experiment with different optimization algorithms and learning-rate strategies.
